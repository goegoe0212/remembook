# 機能一覧

## コア機能

### 本の登録
- タイトル・著者・ISBN の入力
- 表紙画像の登録（カメラ撮影 / ライブラリ選択）
- ジャンル・タグの設定

### 読書管理
- 読了フラグの設定（未読 / 読書中 / 読了）
- 読み始め日・読了日の記録
- 読書メモ・感想の記入

### 購入管理
- 購入日の記録
- 購入場所（書店名 / ECサイト）の記録
- 購入価格の記録

## 一覧・検索機能

- 本棚一覧の表示（グリッド / リスト 切り替え）
- タイトル・著者名での検索
- ステータス（未読 / 読書中 / 読了）でのフィルター
- ジャンル・タグでのフィルター
- 購入日・読了日での並び替え

## 統計・履歴

- 月別・年別の読了冊数グラフ
- 月別・年別の購入冊数・購入金額グラフ
- 読書ペースの可視化

## 今後の検討機能

- 外部サービス連携（Google Books APIによる書籍情報の自動取得）
- データのエクスポート（CSV / JSON）
- iCloudによるデータ同期（iOS）
